프로그램의 일정과 준비물을 살펴보고, AI 아바타와 첫 인사를 연습하는 Android 앱입니다.

가상 사용자 전용 시연

실제 개인 사연·이름·연락처를 입력하지 마세요. AI 연습은 전문 상담이나 응급 도움을 대신하지 않습니다.

앱 배포 확인 중

Android ARM64 휴대폰용입니다.

사용 방법

  1. Android 휴대폰에서 앱 설치 파일을 내려받아 설치합니다.
  2. 앱 첫 화면의 온라인 서버 주소를 기본값으로 유지합니다.
  3. 가상 시연과 음성 처리 안내를 확인한 뒤 프로그램을 선택합니다.

PC·USB 연결 없이 온라인 서버에 접속하는 시연용 앱입니다. 서비스 사용 한도에 따라 AI 연결이 제한될 수 있습니다.
