# 실행 산출물

- `one_step_service-emulator.apk`: 이 PC의 Android x86_64 에뮬레이터용 내부 시연 APK. 일반 ARM 휴대전화용 APK가 아니다.
- `apk-verification.json`: APK 크기·SHA-256·아키텍처·서버 키 미포함 검사 결과.

프로젝트 폴더에서 `scripts/run-demo.ps1`을 실행하면 로컬 API·Whisper·에뮬레이터를 시작하고 앱을 설치한다. 이 APK만 다른 PC에 복사해서 서버 없이 실행할 수는 없다. 상세 설정은 상위 README를 따른다.

공고 자동 갱신은 온통청년 인증키 발급 후 연결할 항목이다. 현재 승인된 공식 공고 1건으로 시연한다. 제출용 시연 영상 파일은 만들지 않았다.
