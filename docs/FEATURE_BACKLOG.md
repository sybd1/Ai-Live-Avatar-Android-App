# 기능 변경과 미해결 과제

기준일: 2026.10.25. 사용자 확정 요구사항과 실제 구현 상태를 구분한다. 구현·검증 결과는 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)에 기록한다.

## 확정한 변경 범위

1. **마이크 기반 실시간 대화:** 연습 시작 후 발화마다 녹음·확인·전송 버튼을 누르지 않고 선택한 공고·장면 안에서 AI 아바타와 대화한다. 사용자가 확정한 방식은 **가상 대사 스트리밍 우선, 공식 정책 정보는 근거 확인 후 별도 안내**다. 가상 대사의 전체 생성·의미 검사를 기다리지 않으며 비평가 지침·실시간 금지 표현 감시를 유지한다. 추천에 반영할 선호의 사용자 확인은 유지한다.
2. **중단 권한:** ‘멈추기·잠깐 쉬기’는 마이크·음성·아바타 출력을 즉시 중지하고 상황을 보존한다. 명시적으로 재개한 경우에만 다시 듣는다. ‘오늘은 여기까지’는 대화를 먼저 끝내며 사후 설문을 강요하지 않는다. 앱 전환·잠금 때도 음성을 멈춘다.
3. **이용자 직접 응답:** 시뮬레이션 직전·직후 불안도·무기력·우울감·고립감·자존감을 같은 문항으로 확인한다. AI가 목소리나 말투에서 감정을 진단하지 않는다. 응답을 건너뛸 수 있고 대화 진행 능력이나 추천 자격 평가에 사용하지 않는다.
4. **이용자 자신의 기록·그래프:** 누적된 개인 응답과 전후 변화를 볼 수 있게 한다. 자존감과 나머지 항목의 점수 방향을 구분하고 미응답은 0점으로 채우지 않는다. 임상 진단·치료 효과·종합 회복 등급으로 설명하지 않는다.
5. **실제 Android 휴대전화:** 연결·기기 구조 확인 후 해당 기기로 빌드·실행·디버깅한다. 에뮬레이터의 실행 성공을 실기기 성공으로 대신하지 않는다.
6. **작업 순서:** 기능 변경·추가 → 실제 기기에서 통합 동작 확인 → 전체 병목 측정·최적화. 구현 중 발견한 크래시·동작 불능은 즉시 수정하되 독립적인 사전 최적화를 반복하지 않는다.

## 구현에서 제외한 기능

| 기능 | 상태와 이유 | 이후 검토할 조건 |
| --- | --- | --- |
| 관리자 화면·계정·권한·이용자 감정 기록 조회 | **사용자 요청으로 이번 구현에서 제외.** 이용자 본인의 기록 조회와 구분한다. | 향후 별도 요청 시 담당자 범위·이용자 동의·공유 범위·접근 통제를 먼저 정해야 한다. |
| 실제 기관·상담사에게 기록 공유 | 관리자 기능과 함께 제외. 자동 공유하지 않는다. | 실제 기관과 데이터 처리·보관·삭제·권한 정책 합의 필요. |
| AI 감정·질환 진단과 회복 점수 | 서비스의 비평가 원칙에 따라 제공하지 않음. | 직접 응답한 현재 상태를 보여주는 기능으로 대체. |

## 개발·연동이 남은 항목

| 항목 | 현재 부족한 부분 | 해결·완료 기준 |

| 실시간 음성 대화 | Gemini Live 중계·마이크 PCM·아바타 스트리밍을 구현. 가상 대사와 공식 정책 도구를 분리한 합성 음성 검사가 통과함. | 실제 사람의 작은 발화·긴 망설임·소음·반향·자막 정합성은 실기기 시연으로 추가 확인. |

| 온통청년 자동 갱신 | 인증키 발급·실제 응답 확인 대기. | 키·명세 확인 후 갱신과 변경 감지 구현. 키 없이 연동 완료로 보고하지 않음. |
| 공식 공고 확장 | 승인된 초기 공고는 ‘따뜻한 집’ 1건. 상세 시간·준비물 등에 확인 필요 항목 존재. | 공식 출처·회차·확인일로 보완. 없는 정보를 AI가 채우지 않음. |
| 실제 이용자 데이터 운영 | 현재 무료 Gemini 가상 사용자 시연만 승인됨. | 실제 사연·개인정보 처리에 맞는 공급자 조건을 별도로 확정. 동의만으로 무료 서비스 제한이 해결된다고 보지 않음. |

| 통합 성능 | 전체 문장 검사 대기를 제거하고 PCM 전달·버퍼 상한·DB 조회·기록 화면 페이지 처리를 개선. 합성 음성 1건에서 발화 종료 후 첫 서버 음성 조각 약 1.4초 확인. | 표본 1건이며 휴대폰 재생 시작 시간·평균·상위 지연을 뜻하지 않음. 실기기 음성 품질·장시간 발열과 메모리 추이는 추가 확인. |

## 문서 적용 기준

세 설계 문서의 과거 버튼 녹음·수동 전송·세션 전용 저장 설명은 기존 구조의 기록이다. 새 개발에서는 이 문서의 연속 음성 대화와 개인 상태 기록 요구사항을 우선 적용한다. 대화·음성은 장기 저장하지 않으며 직접 응답한 상태 기록과 분리한다. 기능 요구사항을 문서에 추가했다는 이유로 구현 완료로 표시하지 않는다.

## 정확성의 적용 범위

공식 정책 답변은 서버가 등록된 근거·공고 버전을 확인하고 확인되지 않은 항목을 ‘확인 필요’로 안내한다. Live의 정책 조회 도구와 음성 인식에서 확인한 정책 질문을 이 경로로 분리한다. 가상 대사는 사용자 승인에 따라 전체 사전 검사를 생략하므로 이전의 ‘모든 문장 검증 후 재생’을 보장하지 않는다. 실시간 표현 감시와 지침은 AI 오류를 완전히 없애는 수단이 아니며, 정책 질문 분류 누락·도구 호출 누락·자막 지연도 남은 검증 과제로 관리한다. 가상 대사를 실제 기관 정보로 제시하지 않는다.
