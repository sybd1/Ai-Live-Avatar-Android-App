# 공유와 새 환경 검사

기준일: 2026.10.25 (한국 시간). 실제 개인 사연을 사용하는 서비스 운영 승인을 뜻하지 않는다.

## 배포 구성

- 소스: 비공개 GitHub 저장소. .env·DB·도구·모델 원본·APK·개인 기록은 Git에 넣지 않는다.
- Windows 실행 ZIP ([배포 페이지](https://github.com/Hackathon-Team-Ongi-One-step-service/One-Step-Service/releases/tag/mvp-2026-10-25)): 서버 JAR·ARM64 APK·공식 공고·설치/실행 스크립트·외부 자산 고지. 비밀키와 외부 도구 자체는 포함하지 않는다.
- 도구 설치: 공식 PowerShell·Temurin Java·PostgreSQL·Google Platform Tools의 버전·다운로드·체크섬을 고정한다. Android 도구에는 약관 동의를 받는다.
- 현재 일반 시연 경로: Windows x64 PC + USB 디버깅이 켜진 ARM64 Android 휴대폰 + 본인의 Gemini 키. PC 서버와 USB를 유지한다.

## 검사 범위

| 검사 | 확인하려는 내용 |
| --- | --- |
| Windows 새 폴더 | 원래 Java·PowerShell 경로와 도구를 사용하지 않고 새 도구 설치, 별도 DB·포트·드라이브로 실행 |
| 키 없는 첫 실행 | 실제 공고 초기 등록·탐색과 AI 연결 필요 안내 |
| 이용자 흐름 | 가상 인물로 탐색·출처·사전 체크·Live 음성·중단/재개·종료·사후 체크·그래프·기록 삭제 |
| 공개 파일 검사 | .env 비밀값·개인 데이터·녹음·개발 도구가 업로드/ZIP에 포함되지 않는지 확인 |
| GitHub 별도 호스트 | 새 checkout·Java/Node 설치·별도 PostgreSQL로 소스 빌드, 검사와 API/공고 등록 |

## 확인한 결과

- **Windows 격리 설치 통과:** 기존 Java·PowerShell PATH를 제외하고 실행 ZIP을 새 폴더에 풀었다. 공식 PowerShell 7·Java 21 런타임·PostgreSQL·ADB를 별도로 준비했다. 서버 18080·DB 55433·드라이브 Q:로 원래 실행과 분리했다.
- **첫 실행 통과:** 키 없이도 공식 공고 1건을 자동 등록하고 탐색 API가 응답했다. AI는 연결 필요로 표시했다. 공고 파일 경로 인자 분리와 한글 드라이브 별칭 중복 문제를 발견해 수정했다.
- **격리 환경 Live 통과:** 합성 음성을 PCM으로 전송해 스트리밍 응답을 받았다. 한 건에서 발화 종료 후 첫 서버 음성 조각 약 1.36초를 확인했다. 공식 날짜 질문은 검증된 사실·별도 음성으로 안내했고 그동안 가상 음성이 섞이지 않았다. 실제 휴대폰의 재생 지연·평균·상위 지연 측정은 아니다.
- **지도 연동 통과:** 공개 장소를 가상 출발지로 주소 검색·도보 경로를 조회했다. 경로 단계와 조회 시각이 있고 도착지가 공식 공고의 장소와 일치했다. 실제 이용자 위치는 사용하지 않았다.
- **GitHub 별도 호스트 통과:** [Actions 실행 40196715946](https://github.com/Hackathon-Team-Ongi-One-step-service/One-Step-Service/actions/runs/40196715946). 새 Ubuntu 호스트와 PostgreSQL에서 서버 빌드·검사, npm ci, 라이선스·해시가 고정된 아바타 준비, 모바일 타입·음성 상태 검사, 패키징한 API 시작·공고 등록을 통과했다. 기록 비동기 수정이 포함된 검사 소스는 `42a39f2ac9fc7c97e8d76f105a1c97626a1fa6c3`이며 이후 커밋은 검사 결과·설치 안내 문서 정리다. CI에 공급자 비밀키를 제공하지 않았다.
- **이용자 흐름 확인:** 에뮬레이터에서 공식 출처 열기·복귀, 다섯 항목의 연습 전후 자기 응답, Live 대화·일시정지·재개·종료와 수치 그래프를 확인했다. 저장·삭제 완료 전에 화면을 읽던 비동기 파일 작업을 수정했다. 수정 APK에서 0점 응답 보존과 삭제 직후 0회 표시를 확인했다. 오디오 파일 생성·아바타 자산 복사도 완료를 기다리도록 수정했다.
- **배포 파일 검사 통과:** 소스와 ZIP 내부의 APK·JAR를 열어 설정된 비밀값 미포함을 검사했다. 실제 설정·DB·도구·녹음·진단용 UI 덤프는 배포하지 않는다.

동일 PC의 새 폴더 검사를 다른 노트북 실물 검사로 설명하지 않는다. GitHub Actions도 실제 휴대폰의 음성·반향·발열 검사를 대신하지 않는다.

## 남은 이용 조건

- 비공개 저장소의 팀원 접근 권한과 각자의 API 키 준비가 필요하다.
- 키 없이 모든 AI 기능이 동작한다고 설명하지 않는다. 유료 계정·호스팅으로 자동 전환하지 않는다.
- 현재 공고는 1건이며 세부 시간·준비물·정책 자동 갱신 등은 [FEATURE_BACKLOG.md](FEATURE_BACKLOG.md)에 기록한 상태다.
- 실제 발화·소음·반향과 장시간 안정성, 다른 OS·CPU의 설치는 별도 확인한다.
